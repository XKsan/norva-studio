# NORVA STUDIO media library

All current visuals are temporary original SVG layout studies, not documentary evidence or client work. Replace each file at the same path and filename to preserve the website layout.

- Photography: WebP/JPEG, 1800px long edge, ideally 200–700KB.
- Keep the current composition/aspect ratio close to the existing image.
- Documentary stills: landscape 16:9 or 3:2.
- Field covers: 4:5 or 3:2; the website uses object-fit cropping.
- Large video files should be hosted externally (YouTube/Vimeo) and embedded; do not commit source footage to GitHub Pages.

# NORVA STUDIO — first complete media/layout package

## What this package contains
- 13 temporary SVG visual studies, already sized to a 16:10 canvas (1440×900).
- Updated Works and Field pages.
- Three Works detail pages: Photography, Documentary & Film, A Little Ant Matter.
- Field Notes page with three topic sections.
- A small additional stylesheet for galleries, responsive cards and the motion placeholder.
- Media manifest and video replacement notes.

## Important
These are temporary design studies, not real NORVA photographs, client projects, or documentary footage. No fake video is included. The documentary page has a subtle animated graphic placeholder; later replace it with an original video or hosted embed.

## Upload
1. Unzip this package.
2. Open the existing GitHub repository `XKsan/norva-studio`.
3. Upload the contents of this package into the repository root, preserving folder structure. Allow the two HTML pages (`works.html`, `field.html`) to replace the existing files.
4. Commit to `main`; GitHub Pages will deploy automatically.

## Replacing images later
Keep the path and filename unchanged. Replace each `.svg` with a `.webp` only if you also update the image extension in the HTML/CSS and media manifest. Easiest path: retain `.svg` filenames by replacing their contents with updated SVG artwork, or ask for a one-time bulk path update when the real images are ready.

Recommended real image export: WebP/JPEG, 1800px long edge, 200–700KB. Keep original aspect ratio close to the existing 1440×900 layout. Host large videos externally (YouTube/Vimeo) rather than committing source footage to GitHub Pages.
